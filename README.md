# Campus TeamUp

A platform for university students to publish project ideas, specify required skills, and form teams through structured join requests.

## Tech Stack

- **Frontend:** React + TypeScript + Tailwind CSS
- **Backend:** PHP 8+ REST API
- **Database:** MySQL
